# Generated service images

`services-a.png` and `services-b.png` are matching image sheets generated for this website. Each is a square PNG with three columns and four rows, containing two different compositions for each service. Their original generated pixels are preserved.

The website crops the matching cell with CSS and crossfades between the two sheets. Both sheets are shared across the eleven cards and load when the service section approaches the viewport.

| Cell | Service |
| --- | --- |
| Row 1, column 1 | Flyers and brochures |
| Row 1, column 2 | Letterhead and business cards |
| Row 1, column 3 | Posters |
| Row 2, column 1 | Mug printing |
| Row 2, column 2 | Document printing |
| Row 2, column 3 | ID card printing |
| Row 3, column 1 | Panaflex |
| Row 3, column 2 | CV / Resume |
| Row 3, column 3 | Urdu and English composing |
| Row 4, column 1 | Online application assistance |
| Row 4, column 2 | Digital marketing |
| Row 4, column 3 | Unused print workspace illustration |

These are illustrative service images, not a customer portfolio.
